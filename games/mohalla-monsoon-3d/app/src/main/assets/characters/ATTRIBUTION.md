# Character asset attribution

The Android build downloads the Khronos glTF Sample Asset **Cesium Man** to exercise rigged animation and embedded base-colour texture rendering.

- Note: the source model includes the Cesium logo/trademark. This is an interim technical asset, not the final custom Mohalla Monsoon rainwear character.

Image decoding uses [stb_image](https://github.com/nothings/stb), released into the public domain by its author.
